## 📊 Problem-Solving Approach

For every problem, I focus on:

1. Understanding the problem
2. Identifying the pattern
3. Developing the approach
4. Writing a clean Java solution
5. Analyzing Time Complexity
6. Analyzing Space Complexity
7. Testing with examples and edge cases
8. Optimizing the solution whenever possible
