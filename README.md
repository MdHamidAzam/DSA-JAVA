## 🧠 Problem-Solving Approach

For each problem, I aim to follow a consistent process:

1. **Understand** the problem statement and constraints.
2. **Identify** the relevant data structure or algorithmic pattern.
3. **Develop** a clear approach before coding.
4. **Implement** the solution in Java.
5. **Analyze** time complexity.
6. **Analyze** space complexity.
7. **Test** examples, edge cases, and boundary conditions.
8. **Optimize** the solution when a better approach is available.

My focus is on understanding **why a solution works**, not just memorizing code.
